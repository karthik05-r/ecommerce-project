# E-Commerce Web Application

A full-stack e-commerce web application featuring user authentication, product catalog browsing, cart management, order placement, and payment checkout integration.

---

## 🚀 Features

- **User Authentication**: Secure user registration, login, and session/profile management.
- **Product Catalog**: Browse products by category, view detailed descriptions, images, and pricing.
- **Cart & Wishlist**: Add products to cart, adjust item quantities, and remove items.
- **Checkout & Payments**: Order placement flow integrated with payment gateway (Razorpay).
- **Admin Dashboard**: Manage inventory, create/edit/delete products, and track placed orders.

---

## 🛠️ Tech Stack

- **Backend**: Python, Django
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Database**: SQLite / MySQL
- **Payment Gateway**: Razorpay API
